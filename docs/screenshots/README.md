# Screenshots

Drop PNGs here with the names referenced in `../index.html`:

- `hero.png` — main window, Atlas tab open, a trajectory or sweep rendered
- `trajectory.png` — Denoise Trajectory 3D PCA view with thumbnails along the curve
- `sweep.png` — Guidance Sweep grid with the drift curve above it
- `bench.png` — Compositional Bench grid with the per-category scoring panel

The page falls back to a dashed placeholder box when a file is missing, so adding and removing images is safe.

Recommended: 1600×1000 or similar, PNG, under 500 KB each. Trim with `pngquant --quality 70-85 in.png -o out.png` if large.
